---
name: ctl-code-driven-docs
description: Generate and maintain README.md file that documents everything there is to know about the project, using code as the source of truth.
---

When generating the documentation consider the following topics:

- Title
- Table of Contents
- Overview/Introduction/Brief: What is this project about?
- Terminology used
- Domain/Business logic explanation
- Architecture - infrastructure, components, how they connect, diagrams
- Setup
    - Prerequisites, related knowledge and topics
    - Tools that are needed
    - Tools that are recommended or optional
    - Environment and configuration variables
- How to run, debug and test
- Key code and Complex code and explanation
- FAQ and Troubleshooting
- References - links, articles, etc.
- Anything else you might consider important.

The documentation should be easy to follow for newcomers, and detailed enough to be the point of reference.
