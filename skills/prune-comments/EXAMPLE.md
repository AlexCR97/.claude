# Examples — prune-comments

---

## 1. Prune the current git changes (default)

```bash
/prune-comments
```

Scans the current diff (staged + unstaged). Run before a commit so comment noise never reaches review.

---

## 2. Prune a single file

```bash
/prune-comments file src/Orders/OrderService.cs
```

---

## 3. Prune a directory

```bash
/prune-comments dir src/Orders
```

Useful after a feature slice, where the same narration repeats across new files.

---

## 4. Prune the current branch

```bash
/prune-comments branch
/prune-comments branch develop
```

---

## 5. Prune the whole codebase

```bash
/prune-comments all
```

One-off cleanup. Expect a large diff — review it as a diff, not as a report.

## The Ladder in Practice

### Rung 1 — obvious from the code

```cs
// Set the user's name
user.SetName(command.Name);
```

Removed. The line says it louder than the comment.

### Rung 2 — inferable from the code

```cs
// Returns null when no product matches the id
public Product? Find(int id) => _products.FirstOrDefault(p => p.Id == id);
```

Removed. `Product?` and `FirstOrDefault` already say it.

### Rung 3 — mildly complex, still inferable

```py
# Group the orders by customer and keep only the customers with more than one order
repeat_customers = {c: o for c, o in groupby_customer(orders).items() if len(o) > 1}
```

Removed. Costs a second read of the comprehension, not a lookup.

### Rung 4 — the surrounding context answers the "why"

```cs
public async Task<bool> RenewExpiringPoliciesAsync(CancellationToken cancellationToken)
{
    // Only renew policies that are close to expiring
    var due = _policies.Where(p => p.ExpiresOn <= _clock.UtcNow.AddDays(30));
```

Removed. The method name is the comment.

### Rung 5 — survives

```cs
// Provider rejects batches over 250; larger payloads fail with an opaque 400.
const int BatchSize = 250;
```

Kept and tightened. The number is arbitrary from inside the code, and nothing in the file says where it came from.

## Before / After

Before:

```cs
/// <summary>
/// Processes the order.
/// </summary>
/// <param name="order">The order.</param>
/// <param name="cancellationToken">The cancellation token.</param>
internal async Task ProcessAsync(Order order, CancellationToken cancellationToken)
{
    // Guard against null
    if (order is null) return;

    // Loop through each line and calculate the total
    var total = order.Lines.Sum(line => line.Price * line.Quantity);

    // We use 3 here
    // because the gateway will start throttling us if we go higher than that,
    // and when it throttles it returns a 200 with an empty body, which is very
    // hard to debug, so we keep the concurrency low on purpose.
    var semaphore = new SemaphoreSlim(3);

    // Save the order
    await _repository.SaveAsync(order, cancellationToken);
}
```

After:

```cs
internal async Task ProcessAsync(Order order, CancellationToken cancellationToken)
{
    if (order is null) return;

    var total = order.Lines.Sum(line => line.Price * line.Quantity);

    // Gateway throttles above 3 concurrent calls and signals it with a 200 and an empty body.
    var semaphore = new SemaphoreSlim(3);

    await _repository.SaveAsync(order, cancellationToken);
}
```

Five comments removed, one kept and cut from four lines to one. The doc comment went too: the member is `internal`, and every tag restated the signature IntelliSense already shows.

## What It Will Not Touch

```py
result = compute(value)  # type: ignore[arg-type]
```

```cs
// <auto-generated/>
```

```js
// eslint-disable-next-line no-console
```

```cs
// TODO(#4821): drop once the legacy sync path is retired.
```

Directives are code. Headers are legal. A tracked `TODO` carries information the code does not.
