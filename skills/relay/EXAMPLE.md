# Examples — relay

`/relay [focus]`

`[focus]` is free text; it can name a topic, a shape and a language in any order. Omitted, the summary covers the session's most consequential outcome, in the shape the content suits, in English.

| Invocation                                      | Relays                                |
| ----------------------------------------------- | ------------------------------------- |
| `/relay`                                        | the session's main outcome            |
| `/relay perf results of the cache change`       | that topic only                       |
| `/relay blockers only`                          | what is blocked or at risk            |
| `/relay as a table`                             | the main outcome, forced into a table |
| `/relay in Spanish`                             | the main outcome, written in Spanish  |
| `/relay release status, as a table, in Spanish` | that topic, as a table, in Spanish    |

**Refuses:** a session with no outcome worth relaying — it copies nothing.
