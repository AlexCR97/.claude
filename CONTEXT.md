# Ticket Skills

A suite of skills that carries a ticket from its source to finished code: fetching and digesting it, planning the work, implementing it, and recording where a session stopped so another can resume.

## Language

The vocabulary lives in [`skills/ticket-common/GLOSSARY.md`](./skills/ticket-common/GLOSSARY.md). It covers where tickets are kept (tickets home, namespace, product, binding), the code a ticket touches (repository, worktree, project, workspace), the branches work happens on (default branch, protected branch, ticket branch, ticket worktree), and the journal. Use its terms exactly, and add new ones there.
